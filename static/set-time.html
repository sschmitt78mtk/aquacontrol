Fisch-Sicherheitsmodus aktiv

Die Uhrzeit war beim Start nicht per NTP synchronisiert.

CO₂ bleibt ausgeschaltet. Das Hauptlicht läuft im 10-Stunden-Notprogramm, die PWM-Hintergrundbeleuchtung bleibt aus und das Mondlicht signalisiert SOS.

Geben Sie die lokale Zeit nur ein, wenn sie korrekt ist. Danach wird der normale Zeitplan einschließlich CO₂-Steuerung fortgesetzt.
